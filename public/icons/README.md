# Ícones PWA

Substitua estes placeholders pelos ícones oficiais do CBMAP nas dimensões:

- `icon-192.png` — 192×192, com padding apropriado para "maskable"
- `icon-512.png` — 512×512, idem
- `apple-touch-icon.png` — 180×180 (opcional)

Ferramenta recomendada para gerar: https://maskable.app/editor

Validar com a Coordenação antes do deploy (assets oficiais — ver `docs/decisions.md` D-019).
